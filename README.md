# НейроБиолоджислоп · GutSignal: диагностика колоректального рака по микробиому кала

Решение кейса «Кишечный микробиом и колоректальный рак» (хакатон Genotek × ЦУ). Бинарная классификация КРР (1) и контроль (0) по 849 таксонам и метаданным, метрика ROC AUC.

## Результаты

| Оценка | ROC AUC |
|---|---|
| Платформа, публичная часть test | **0.9206** |
| Validation (83 образца, один раз), 95 % ДИ 0.842–0.960 | 0.9076 |
| «Новая страна»: обучение на 4 странах, проверка на пятой | 0.890 |
| Кросс-валидация 5×5 внутри train | 0.936 |

## Что в репозитории

- `НейроБиолоджислоп.pdf` — презентация (9 слайдов, этапы 0–8).
- `genotek_v4.ipynb` — итоговый ноутбук с выводами: данные, разбиение, предобработка, оценка, модель, интерпретация, таблица ответа. Все seed = 42.
- `submission_v4_scores.csv` — таблица ответа: `sample_id`, `label` (скор КРР от 0 до 1).
- `experiments/` — скрипты и логи проверенных вариантов улучшения (30 вариантов, ни один не прошёл заранее заданное правило отбора). Пути в скриптах локальные.
- `requirements.txt` — версии библиотек (Python 3.14).

## Метод кратко

1. Разбиение 80/20 по «страна × диагноз» (seed 42) до любого анализа; кросс-валидация и проверка «новая страна» только внутри train.
2. Предобработка по train: log10(доля + 1e-5), фильтр таксонов ≥ 5 % образцов, остатки после вычитания вклада возраста, log10(глубины секвенирования) и страны (регрессия учится на train и применяется к новым данным без пересчёта).
3. Признаки: таксоны + 4 «ротовых» признака из литературы (сумма и число ротовых таксонов, богатство, индекс Шеннона).
4. Модель: 0.7 · случайный лес + 0.3 · L2-логистическая регрессия.
5. Интерпретация: перестановочная важность; проверка 7 гипотез из литературы.

## Ограничения

Модель частично использует глубину секвенирования (перестановка внутри страны снижает AUC на 0.080); на США AUC на validation 0.51 (14 образцов); validation мала (±0.06). Подробности в презентации и ноутбуке.

## Запуск

Данные организаторов (`train.csv`, `test.csv`) в репозиторий не входят. Положите их рядом с ноутбуком или укажите папку через переменную окружения `PLATFORM_DATASET_DIR`, затем выполните ноутбук целиком (около 5 минут).
